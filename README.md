# coreinfo
一个专门为 Go 语言开发者和系统运维人员设计的硬件特性检测工具。

<img width="752" height="884" alt="image" src="https://github.com/user-attachments/assets/48b18e19-5c32-44d9-a802-aacdad280475" />

这个项目是一个专门为 Go 语言开发者和系统运维人员设计的硬件特性检测工具。它将微软 Sysinternals 家族中的专业内核检测工具 Coreinfo 与 Python 的图形化界面（Tkinter）相结合，旨在快速判定当前处理器对 Go 编译指令集等级（GOAMD64）的支持情况。

以下是该项目的核心功能概览：

1. 核心判定逻辑：GOAMD64 等级分级
Go 语言从 1.18 版本开始引入了 AMD64 架构的分级优化。这个工具会自动解析 CPU 支持的指令集（如 AVX, AVX2, BMI2, POPCNT 等），并直接告诉你该机器属于哪个等级：

v1: 基础的 64 位支持（如早期的 Pentium/Athlon）。
v2: 增加了对 POPCNT、SSE4.2 等指令的支持。
v3: 现代主流标准，要求支持 AVX、AVX2 和 BMI2。
v4: 顶级支持，要求支持 AVX-512 系列指令集。

2. 技术亮点与适配
全系统兼容性：经过深度打磨，程序不仅在 Win10/Win11 上运行流畅，还完美适配了 Windows 7。通过独特的“字符清洗”技术，解决了老旧系统下 GUI 渲染乱码的问题。

内核自动识别：程序会根据操作系统的位数（32位或64位）自动调用对应的 Coreinfo.exe 或 Coreinfo64.exe。

静默静音执行：在点击检测时，所有的命令行调用都在后台完成，不会有黑色的 CMD 窗口闪烁，用户体验丝滑。

指令集可视化：除了判定结果，它还能实时展示具体的指令集特征。支持的指令会以绿色加粗显示，不支持的则以红色标识，直观清晰。

3. 应用场景
性能优化：在部署 Go 编写的程序前，确认服务器支持的 GOAMD64 等级，从而编译出执行效率最高的版本。

硬件排错：快速检查服务器是否开启了虚拟化支持（VT-x/AMD-V）或 NUMA 节点配置。

老旧机器检测：在一些配置较低的老旧办公机上，快速判定其硬件上限。

4. 项目结构
该项目由一个 Python 主程序 core.py 和两个核心组件 Coreinfo.exe、Coreinfo64.exe 组成。通过 PyInstaller 打包后，它就是一个绿色的、单文件的可执行程序，无需安装 Python 环境即可在任何电脑上运行。
